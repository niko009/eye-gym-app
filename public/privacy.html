Русский

Владелец данных: Бакус Михаил, Молдова. Контакт: nikomisha@gmail.com.

Eye Gym — приложение для расслабления глаз, не являющееся медицинским средством. Без входа история тренировок и настройки хранятся локально на устройстве. При добровольном входе мы сохраняем профиль провайдера, настройки и завершённые тренировки в нашей PostgreSQL базе для синхронизации.

  • Google-профиль может включать subject, email, имя и фотографию.
  • Telegram-профиль может включать Telegram user/chat ID, имя, username, язык и фотографию. Email от Telegram не ожидается.
  • Google и Telegram создают независимых пользователей и не объединяются автоматически.
  • Для напоминаний хранятся выбранное время, часовой пояс и Web Push endpoint либо Telegram chat ID после согласия.
  • Secure/HttpOnly cookie хранит только непрозрачный идентификатор сессии.
  • Google Analytics 4 загружается только после отдельного согласия. Идентификаторы Google/Telegram и содержимое тренировок в аналитику не отправляются.

Доступ ограничен текущим аккаунтом. Для удаления или получения копии серверных данных отправьте запрос на контактный email. Локальные данные можно удалить в настройках приложения.

English

Data controller: Mihail Bacus, Moldova. Contact: nikomisha@gmail.com.

Eye Gym is an eye-relaxation application and is not a medical device. Without signing in, workout history and settings stay on the device. After voluntary sign-in, the provider profile, settings and completed workouts are stored in PostgreSQL for synchronization.

  • Google and Telegram accounts create independent users and are never merged automatically.
  • Reminders store the selected time, time zone and a Web Push endpoint or Telegram chat ID only after consent.
  • The Secure/HttpOnly cookie contains only an opaque session identifier.
  • Google Analytics 4 loads only after separate consent and does not receive Google or Telegram identifiers.

Local data can be removed in settings. Contact the address above to request export or deletion of server data.
